# ⚡ 設備單價查詢系統 (Google Sheet 後端 + 現代化前端)

這是一套為工程與設備估價打造的**現代化設備單價查詢系統**。以 **Google 試算表 (Google Sheet)** 作為後台資料庫，支援 10 個（或任意多個）設備分類分頁自由增修項目、金額、廠牌、型號、備註與型錄下載連結，並具備**帳號密碼登入、管理員審核權限、登入時間與日誌紀錄、即時多欄位模糊搜尋、估價詢價單試算與 Excel 匯出**功能。

## 🚀 3 步驟快速串接 Google Sheet

### 第一步：建立 Google 試算表並貼上後端程式碼
1. 開啟 [Google 試算表 (Google Sheets)](https://sheets.new) 建立一份全新空白試算表，命名為「**設備單價資料庫**」。
2. 點擊頂部選單的 **「擴充功能」 ➔ 「Apps Script」**。
3. 將預設編輯器內的內容清空，開啟本專案中的 `google-apps-script/Code.gs`，將全部程式碼複製並貼上到 Apps Script 編輯器中。
4. 點擊上方的 **儲存專案 (💾 圖示)**。

### 第二步：一鍵初始化資料庫 (自動建立 10 大類別與權限表)
1. 在 Apps Script 編輯器上方函式下拉選單中，選擇 **`setupDatabase`**。
2. 點擊 **「執行」**（第一次執行時 Google 會跳出授權視窗，點擊「審查權限」➔ 選擇您的 Google 帳號 ➔ 點擊「進階 (Advanced)」➔ 點擊「前往專案 (不安全)」➔ 點擊「允許」）。
3. 執行完成後返回 Google 試算表，您會發現系統已經自動為您建立好：
   - 📂 **10 個設備分類分頁**（例如 `01_空調主機系統`、`02_高低壓配電系統`... 內含範例資料與欄位）。
   - 👥 **`_用戶權限` 分頁**（內建管理員 `admin` / `admin123` 及一般帳號）。
   - 📋 **`_登入紀錄` 分頁**（自動記錄所有登入時間、帳號、姓名、IP/來源）。

### 第三步：部署為 Web 應用程式 (API 端點)
1. 在 Apps Script 編輯器右上角，點擊 **「部署」 ➔ 「新增部署作業」**。
2. 點選左側齒輪圖示 ➔ 選擇 **「網頁應用程式 (Web app)」**。
3. 設定如下：
   - **說明**：`設備單價查詢 API`
   - **執行身分**：**`我 (您的 Google 帳號)`**
   - **誰可以存取**：**`所有人 (Anyone)`** *(重要！請務必選 Anyone，前端網頁才能連線存取)*
4. 點擊 **「部署」**，複製畫面中產生的 **「網頁應用程式網址 (Web App URL)」** (格式如 `https://script.google.com/macros/s/AKfycb.../exec`)。
5. 開啟前端專案中的 `js/config.js`，將網址貼在 `GAS_API_URL` 欄位中：
   ```javascript
   const CONFIG = {
     GAS_API_URL: "https://script.google.com/macros/s/AKfycb.../exec",
     // ...
   };
   ```

🎉 **完成！** 現在雙擊開啟 `index.html` 即可使用您專屬的 Google Sheet 設備單價查詢系統！

## 📊 Google Sheet 分頁與欄位規範 (雙單價設計)

### 1. 12 大設備分類分頁 (可自由增刪與改名)
系統預設建立 12 大分類分頁：
1. `01_中央監控系統`
2. `02_門禁系統`
3. `03_對講系統`
4. `04_停管系統`
5. `05_網路系統`
6. `06_訪客機系統`
7. `07_多媒體系統`
8. `08_線材`
9. `09_飛利浦燈控系統`
10. `10_其他周邊設備`
11. `11_電子鎖系統`
12. `12_攝影機系統`

每個分類分頁第 1 列為標題，固定包含以下 **7 個欄位**：
| 項目 | 廠牌 | 型號 | 採購成本 | 業務成本 | 備註 | 型錄(下載連結) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| AI 4K 超高畫質網路攝影機 | 海康威視 HIKVISION | DS-2CD3T87G2 | 4,800 | 6,800 | 星光級全彩夜視 | `https://www.hikvision.com` |

> 🔒 **權限與價格資安防護**：
> - **業務人員 (`sales`)**：系統**僅顯示「業務成本」**，採購進貨成本在後端與前端完全保密遮蔽！
> - **採購人員 (`procurement`)**：系統**僅顯示「採購成本」**。
> - **系統管理員 (`admin`)**：可**同時檢視「業務成本」與「採購成本」**，並即時計算毛利額與毛利率。」！

---

### 2. 權限分頁：`_用戶權限` (系統保留名稱)
| 帳號 (Username) | 密碼 (Password) | 姓名/單位 | 狀態 (已啟用/待審核/停用) | 角色 (admin/sales/procurement) | 註冊時間 | 最後登入時間 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `admin` | `admin123` | 系統管理員 | `已啟用` | `admin` | 2026/08/29 10:00 | 2026/08/30 00:10 |
| `sales01` | `123456` | 業務部-張專員 | `已啟用` | `sales` | 2026/08/29 11:20 | 2026/08/29 22:15 |
| `buyer01` | `123456` | 採購部-李經理 | `已啟用` | `procurement` | 2026/08/29 12:30 | 2026/08/29 21:00 |

- **角色欄位 (`Role`)**：
  - `admin`：系統管理員（看雙價格 + 毛利 + 擁有後台審核與帳號管理權限）
  - `sales`：業務人員（看業務價）
  - `procurement`：採購人員（看採購價）
- **狀態欄位 (`Status`)**：只有標記為 `已啟用` 的帳號才能登入系統。
- **最後登入時間**：每次用戶登入成功，系統會自動更新此欄位。

---

### 3. 日誌分頁：`_登入紀錄` (系統保留名稱)
系統會自動追加每一筆登入與註冊申請紀錄（時間、帳號、姓名、結果、備註與角色）。

## 🌟 系統亮點功能

1. **嚴格分級單價控管**：業務只能看到業務售價、採購只能看到採購進價，商業機密不外洩。
2. **管理者雙價與毛利分析**：管理者登入後可同時檢視採購與業務價，即時計算專案利潤。
3. **多維度極速搜尋**：同時比對「設備名稱、廠牌、型號、備註規格」，支援即時高亮標記。
4. **多分類 Tab 切換**：快速瀏覽 10 大分類，或一鍵跨全類別全域檢索。
5. **詢價單 / 估價試算車**：勾選所需設備加入詢價單，依不同角色單價自動試算總額，支援**一鍵匯出 Excel (CSV)** 或**列印標準報價單**。
6. **管理員後台面板**：管理員登入後可直接在網頁端審核新帳號、修改角色權限及檢視最新登入日誌。
